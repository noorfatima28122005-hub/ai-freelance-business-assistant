# AI Freelance Business Assistant

An AI-powered freelance business management platform that helps freelancers manage clients, projects, tasks, deadlines, and business priorities through a REST API and web dashboard.

## Features

- User authentication with JWT
- Client management
- Project management
- Task management
- Dashboard with business statistics
- AI-powered freelance business assistant
- Deadline and priority tracking
- Protected API routes
- Rate limiting
- CORS protection
- Swagger/OpenAPI API documentation
- SQLite database
- Docker containerization
- Responsive web dashboard

## Tech Stack

### Backend
- Node.js
- Express.js
- SQLite
- JWT Authentication
- Swagger / OpenAPI
- Docker

### Frontend
- HTML
- CSS
- JavaScript

### Security
- JWT authentication
- Password hashing
- Protected routes
- Rate limiting
- CORS configuration
- Environment variables
